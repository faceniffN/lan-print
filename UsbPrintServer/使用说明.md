# LanPrintServer - USB 打印机网络共享小工具

## 这是什么
跑在接 USB 打印机的那台 Windows 上，监听 9100 端口（网络打印机标准 RAW 协议），
让局域网里任何设备（Windows / Mac / iPhone / 安卓）都能直接往这台打印机发任务，
不依赖 Windows 自带的"共享打印机"那套工作组/权限设置。

## 使用步骤

1. 把 USB 打印机用数据线接到这台 Windows，装好官方驱动，**先在本机测试能正常打印**。
2. 双击 `LanPrintServer.exe`（第一次启动会在右下角托盘出现图标，双击图标打开主窗口）。
3. 在"选择本机打印机"下拉框里选你那台 USB 打印机。
4. 点 **启动共享**。
5. 窗口会显示本机 IP，例如 `192.168.1.23:9100`。

## 其他设备怎么连

### Windows（其他电脑）
设置 → 蓝牙和设备 → 打印机和扫描仪 → 添加设备 → "添加手动设置" →
选 **使用 TCP/IP 地址或主机名添加打印机** → 设备类型选 "TCP/IP 设备" →
IP 地址填上面那个 IP（不含端口），端口名随便填 → 装驱动时选你打印机型号即可。

### Mac
系统设置 → 打印机与扫描仪 → 添加打印机 → 选 "IP" 标签 →
地址填本机 IP，协议选 **Line Printer Daemon - LPD** 或 **AirPrint**，队列留空。

### iPhone / 安卓 / 其他
注意：**这个工具实现的是 RAW 9100 协议，不支持 AirPrint**。
iPhone 想直接无线打，需要在打印机上装一个支持 AirPrint 的服务（或用路由器/NAS 的 AirPrint 功能）。
安卓一般有"添加网络打印机"选项，填 IP:9100 即可。

## 防火墙
第一次启动时如果别人连不上，多半是 Windows 防火墙挡了。
用**管理员权限**开 PowerShell，跑一条命令放行：

```
New-NetFirewallRule -DisplayName "LanPrintServer 9100" -Direction Inbound -Protocol TCP -LocalPort 9100 -Action Allow
```

## 托盘
- 点窗口右上角 X：**不会退出**，缩到托盘继续跑。
- 右键托盘图标可退出。
- 勾选"开机自动启动"后，开机自动在托盘运行。

## 注意
- 主机必须开机、本工具必须在跑，别人才能打。
- 只能转发"裸打印数据流"（PCL/PS），扫描功能不能通过这个工具用。
- 配置保存在 exe 同目录的 `config.json`。

## 文件说明
- `LanPrintServer.exe` — 编译好的单文件程序，拷到任何 Windows 10/11 64 位机器都能直接跑。
- `Program.cs` / `UsbPrintServer.csproj` — 源码，想改功能（比如加 AirPrint、改端口默认值）直接改完 `dotnet publish` 即可。
